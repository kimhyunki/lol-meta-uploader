LoL Meta Uploader

개인이 자기 맥에서만 실행하는 리그 오브 레전드 복기용 앱입니다. 리플레이에서 자동으로 녹화한 하이라이트 영상을, 사용자가 버튼을 누를 때 사용자 본인의 YouTube 채널에 올립니다.

A personal League of Legends review app that runs only on the owner's own computer. When the user clicks a button, it uploads a highlight clip to the user's own YouTube channel.
