개인정보처리방침 (Privacy Policy)

최종 수정 2026-11-01

  • 이 앱은 사용자 본인의 컴퓨터에서만 실행되며, 운영자가 따로 운영하는 서버가 없습니다.
  • Google 계정 권한(youtube.upload, youtube.readonly)은 사용자가 고른 하이라이트 영상을 사용자 본인의 YouTube 채널에 올리고, 업로드 처리 상태와 채널 이름을 확인하는 데만 씁니다.
  • OAuth 토큰은 사용자 컴퓨터의 로컬 데이터베이스에만 저장되며 제3자에게 보내지 않습니다.
  • 사용자는 언제든 앱에서 연결을 끊거나 Google 계정 권한 페이지에서 접근을 취소할 수 있습니다.

The app runs only on the user's own computer; there is no operator server. Google permissions are used only to upload clips the user selects to the user's own YouTube channel and to read upload status and channel name. Tokens stay in a local database on the user's computer and are never shared. Access can be revoked at any time from Google Account permissions.

YouTube API Services are used; see the YouTube Terms of Service and Google Privacy Policy.
